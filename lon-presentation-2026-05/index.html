Bloque 1 · LON Cobertura del territorio temático

Cinco clusters trabajados con consistencia.

No buscamos palabras sueltas. Construimos territorios temáticos completos para que cada cluster sostenga al siguiente y todo el contenido funcione como sistema.

CLUSTER 1
Brand
Cobertura completa del nombre de marca y sus variantes. Asegura que cuando alguien busca por nombre del proyecto, encuentra contenido propio en primera página.
CLUSTER 2
Inversión Filipinas
El corazón del negocio. Keywords de intención clara de compra: invertir en Filipinas, comprar terreno, inversión inmobiliaria 2026.
CLUSTER 3
Eco & Sostenible
Posicionamiento diferencial: eco-villas, eco-second-homes, auditoría verde. Captura tráfico de inversores conscientes.
CLUSTER 4
Cultural & Estacional
Tráfico alto en momentos puntuales: navidad en Filipinas, calidad de vida, cultura. Trae usuarios curiosos que luego convierten.
CLUSTER 5
Educacional / Decisión
Acompaña al inversor en su proceso: errores al invertir, perfil del comprador internacional, costes escondidos.

Bloque 2 · Kwin Partners Lo que hemos hecho hasta ahora

Información ordenada antes de empezar.

Antes del kickoff oficial, hemos descargado, inventariado y clasificado toda la información del cliente. Cuando arranque la producción, partimos de un sistema limpio.

Estructura de información clasificada

📁 Kwin Partners
├─ 00-readme // guía de navegación
├─ 01-clientes // base de clientes activos
├─ 02-manual-kwin // sistema visual completo
├─ 03-ventas // propuestas y materiales comerciales
├─ 04-kwin-llc-corp // procesos jurídicos LLC
└─ 99-pii-confidencial // datos sensibles, acceso restringido

Cada carpeta sigue una convención de nombres consistente. Lo que llega del cliente se cataloga sin tocarlo; solo se trabaja sobre la copia limpia. Trazabilidad total.

01
Descarga e inventario

Todo el material del Drive del cliente, listado con tamaño, formato y conclusión.

02
Catalogación del sistema visual

20+ recursos del manual de marca identificados: logo, isotipo, variantes, paleta, tipografías.

03
Renombrado y limpieza

Convención de archivos aplicada · versión limpia lista para re-subir al Drive del cliente.

04
Construcción del cerebro al 40%

Subset operativo del sistema OH WOW! adaptado para que Kwin trabaje con el orden necesario sin recibir el stack completo.

05
Kickoff oficial · 1 junio 2026

Producción real arranca con todo el sistema operativo y los flujos definidos.

🔐
Vault cifrado por usuario

Cada persona guarda sus API keys (Anthropic, OpenAI, Google…) cifradas en reposo. El servidor descifra solo cuando hace falta y deja registro en el audit log.

⚙️
.mcp.json personalizado

Cada miembro descarga el archivo de configuración de Claude Code con sus propios accesos ya inyectados. No hay que copiar claves a mano nunca más.

👥
Tres roles claros

Admin gestiona equipo y permisos. Member trabaja con lo asignado y mantiene su vault. Viewer accede a contenidos en solo lectura.

📊
Audit log completo

Cada acceso a una credencial, cada cambio de permiso y cada login queda registrado. Visibilidad total para el admin, trazabilidad para el equipo.
